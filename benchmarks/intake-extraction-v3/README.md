# Provider-compatible intake experiment v3

Synthetic-only, non-production follow-up to frozen v2. V1/v2 artifacts, pinned
sources, results and failures remain unchanged. No model is qualified and no
production profile, route, store, confirmation or amendment authority changes.

## Exact provider/local boundary

`IntakeExtractionV3.kt` derives a new provider schema once at export. It removes
exactly five reviewed keywords from the frozen v2 schema:

- `uniqueItems:true` on both suggestion branches' `unresolvedFields` arrays;
- `maxLength:4000` on both branches' `sourceExcerpt` strings;
- `maxLength:4000` on the context branch's `context.content` string.

Every other schema value, required field, null branch, enum, array/integer bound
and lower string maximum stays equal. `minLength:1` remains on those three strings.
Instructions, example and the eight original packet strings are byte-identical to
v2. New profile `context-intake-extraction-v3` belongs to experiment records, not
the raw response or production profile enumeration.

Local validation delegates to the unchanged frozen `IntakeExtractionV2.validate`.
Uniqueness and 4000 UTF-16-code-unit ceilings remain strict whole-response wire
checks. Raw and assembled drafts each retain their independent 12,288-byte limit.
Unique exact-excerpt UTF-16 binding and the unchanged production semantic validator
remain separate stages. There is no trimming, deduplication, inference, repair,
generated disclosure/question, item salvage or permissive fallback.

## Compatibility evidence

The ownership record generated by `experiment.ownership()` binds exact source and
runtime-library/disassembly hashes. It distinguishes provider-enforced structural
constraints, intentionally local-only checks, source binding and semantic authority.
Evidence uses Ollama commit `cc4069396f3ad2c370c53eed2e4a42ac13adab84` and llama.cpp
commit `161755f29e415e2c33efe906e91843c068efd664` from the approved cached source
inspection. It is a source-control-flow audit, not an executed native grammar test,
sampled output or live reliability claim.

The entire remaining schema subset has been inspected, not only removed keywords:

- Objects: converter emits all required keys and no additional-property path.
  Its fixed property order is a stricter serialization subset, not local acceptance.
- Arrays: item rules and maxima 8/10/20 use bounded repetition below the parser's
  2000 threshold; the generated optional first-item/separator rules retain maxima.
- Alternatives/null: explicit schema branches generate alternatives; strings and
  inactive null payloads are not coerced into another type.
- Enums: only finite string literal values are used here.
- Strings: remaining maxima 10/19/128/160/1000 are below the parser threshold.
  A JSON escape is one converter `char` occurrence. Escaped surrogate pairs can be
  more restrictive than raw supplementary characters. Local UTF-16 ceilings can
  separately reject a string accepted under schema code-point counting.
- Integers: the inclusive range 1..366 is converted to finite digit alternatives;
  no decimal, quoted-number or unconstrained-number rule is used for this field.
- Enforcement: non-lazy grammar construction fails closed on parse failure;
  the sampler applies the parsed grammar and rejects invalid next-token candidates.

The original uniqueness and high-repetition findings, exact source ranges and
countervectors remain in
`openspec/changes/provider-compatible-intake-experiment-v3/compatibility-audit.md`.
The user explicitly approved the five-keyword amendment. Any further unsupported
constraint, input change or runtime/path drift blocks readiness, rather than
expanding this allowlist or changing context automatically.

them. Use an existing directory outside the repository, mode `0700`, without
symlink ancestors. Every input is an exclusively created regular file, mode `0600`,

  must represent actual permission. Its presence cannot manufacture permission to

- `replay.json`: version `intake-extraction-replay-v3` and ordered `cases` from a

  `costUsd`: recorded nonnegative bounded numbers or null; counts are integers,
